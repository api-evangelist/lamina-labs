# Lamina Labs

> Near-real-time video infrastructure for LLMs. Lamina Labs' product Simi turns prompts,
> documents, and AI-generated answers into whiteboard-style teaching videos in seconds —
> script, illustration, animation, and narration handled automatically, in 80+ languages.
> The developer surface is a public remote MCP server, authorized by OAuth with PKCE and
> dynamic client registration. Y Combinator Spring 2026, San Francisco.

Generated by the API Evangelist enrichment pipeline on 2026-07-19 from live probes of the
provider's own hosts. Lamina Labs publishes no llms.txt of its own (404).

## Agent surface

- [Simi MCP server](https://api.laminalabs.ai/mcp): Remote MCP server `lamina-simi` v0.1.0, protocol 2025-06-18. Tools only — no resources, no prompts.
- `simi_submit_video`: Submit a video generation job. Params: prompt (1–10000 chars), duration_seconds (1–300, default 60), aspect_ratio (default 16:9), language (default English). Returns job metadata immediately; does not stream progress. Not idempotent.
- `simi_get_video`: Poll a job by job_id. Returns ready (boolean), playback, app_url, and nullable video_url / download_url. Read-only and idempotent.

## Authorization

- [OAuth authorization server metadata](https://api.laminalabs.ai/.well-known/oauth-authorization-server): RFC 8414.
- [OpenID configuration](https://api.laminalabs.ai/.well-known/openid-configuration): identical document served at the OIDC path.
- Authorize: https://api.laminalabs.ai/oauth/authorize — Token: https://api.laminalabs.ai/oauth/token — Register: https://api.laminalabs.ai/oauth/register
- Grants: authorization_code, refresh_token. PKCE S256 required. Public clients supported. Dynamic client registration (RFC 7591) available.
- Scopes: `jobs:create` (submit), `jobs:read` (poll).

## Conventions

- Errors: custom envelope `{"error":{"code","message","details"}}` — not RFC 9457. Codes observed: UNAUTHORIZED (401), VALIDATION_ERROR (400), NOT_FOUND (404, also returned for unsupported methods).
- Rate limits: 120 requests / 60 seconds on /mcp, signalled via x-ratelimit-limit, x-ratelimit-remaining, x-ratelimit-reset.
- No idempotency key: retried submissions create duplicate jobs.
- No webhooks or event stream; the model is submit-then-poll.
